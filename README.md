# אורי – מקבצים מעורבים בכמותי

אתר תרגול לשאלות מהמקבצים המעורבים בכמותי (40 מקבצים × 10 שאלות). אין בו שלב בנייה, והוא רץ ישירות ב־GitHub Pages.

- `index.html`: גיליון התשובות. מראה את ההתקדמות בכל המקבצים, עם סינון לפי "לא נענו", "לבדיקה" ו"נוספו מתמונה".
- `sets/NN.html`: עמוד לכל מקבץ.
  - רשימת מקבצים בצד, עם התקדמות.
  - חיפוש בכל השאלות.
  - בדיקה מיידית של כל תשובה.
  - פתרון מלא לכל שאלה: התשובה הסופית, דרך הפתרון, מוקש נפוץ וסימון אמינות.
- `solutions.html`: עמוד פתרונות ומפתח תשובות שאפשר להדפיס.
- `data/questions.json`: כל 400 השאלות, כולל השאלות שלא צולמו (`status: missing`).
- `data/solutions/*.json`: הפתרונות. `v: false` מסמן פתרון שדורש בדיקה מול הספר.
- `AUDIT.md`: מה חסר ובאילו עמודים.

ההתקדמות נשמרת ב־localStorage של הדפדפן.
