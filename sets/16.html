    הצגת הפתרון

    דרך הפתרון והסבר

    נמצא את y:y³ < y⁵ ⇒ y³(y² − 1) > 0. עבור מספר שלם זה קורה רק כש־y ≥ 2.y⁵ < 243 = 3⁵ ⇒ y < 3.לכן y = 2.נמצא את x:x³ < x² ⇒ x²(x − 1) < 0 ⇒ x < 1 (ו־x ≠ 0).x² < 16 ⇒ −4 < x < 4.לכן x ∈ {−1, −2, −3}.הערכים האפשריים של y − x:2 − (−1) = 3, 2 − (−2) = 4, 2 − (−3) = 5הערך 2 אינו אפשרי: תשובה (2).

    💡 הלקח

    מפרקים כל אי־שוויון לגורמים: y³ < y⁵ ⇒ y ≥ 2, ו־x³ < x² ⇒ x < 1 (ו־x ≠ 0).
