    התשובה הסופית2תשובה (2)2π : 3√3

    צלע המשושה 2r (המעגלים נוגעים). מכל מעגל, 240° נמצאים מחוץ למשושה: 6 · ⅔πr² = 4πr² – השטח האפור. השטח הלבן הוא המשושה: (3√32)(2r)² = 6√3r². היחס 4π : 6√3 = 2π : 3√3.

    נתון: x³ < x²

    איזה מהנתונים הבאים יש להוסיף לנתון בשאלה כדי לקבוע בוודאות כי −1 < x < 0?

    הצגת הפתרון

    התשובה הסופית2תשובה (2)x³ < x⁵

    דרך הפתרון והסבר

    x³ < x² ⇒ x < 1, x ≠ 0. ‏x³ < x⁵ ⇔ x³(x² − 1) > 0 ⇒ x > 1 או −1 < x < 0. יחד: −1 < x < 0.

    מוקשים נפוצים

    x³ < x⁵ ⇔ x³(x² − 1) > 0.
