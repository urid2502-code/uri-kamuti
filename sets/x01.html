    נתון: x > y − z

    איזו מהטענות הבאות בהכרח אינה נכונה?

    הצגת הפתרון

    התשובה הסופית4תשובה (4)z < 0 וגם x < y

    דרך הפתרון והסבר

    נעביר את z לאגף השני: הנתון x > y − z שקול ל־x + z > y.נבדוק את תשובה (4): z < 0 וגם x < y.z שלילי, ולכן x + z < x.יחד עם x < y: x + z < x < y – כלומר x + z < y, בסתירה לנתון.לכן תשובה (4) בהכרח אינה נכונה.דוגמאות שבהן שאר הטענות מתקיימות יחד עם הנתון:תשובה (1): x = 1, y = 0, z = −0.5 – אכן y − z = 0.5 < 1.תשובה (2): x = 0, y = 1, z = 2 – אכן y − z = −1 < 0.תשובה (3): x = −1, y = 0, z = 2 – אכן y − z = −2 < −1.

    💡 הלקח מעבירים אגפים כך שהנתון ייראה כמו הטענות (x + z > y), ואז רואים מיד איזו טענה סותרת אותו.

    ⚠️ המלכודת "בהכרח אינה נכונה" – מחפשים טענה שסותרת את הנתון. לטענות האחרות מספיקה דוגמה אחת שבה הן מתקיימות.

    בחירת מספרים נוחים

    איזו מהטענות הבאות תיתכן?

    התשובה הסופית2תשובה (2)a ו־b אי־זוגיים

    דרך הפתרון והסבר

    אגף ימין, c(c + 1), הוא מכפלה של שני מספרים עוקבים – ולכן תמיד זוגי.לכן גם ab + 3b זוגי.ab (עם b ≥ 1) זוגי בדיוק כש־a זוגי.3b זוגי בדיוק כש־b זוגי.סכום זוגי – רק כששני המחוברים באותה זוגיות: a ו־b זוגיים יחד, או אי־זוגיים יחד.(1) ו־(4): a זוגי ו־b אי־זוגי ✗.     ⚠️ המלכודת c(c + 1) זוגי תמיד – לא צריך לדעת מהו c. זה הנתון שמכריע את השאלה.

    הצגת הפתרון

    דרך הפתרון והסבר

    בסרטוט שלפניכם מתומן משוכלל שצלעו 2 ס"מ. העבירו בו את האלכסונים AE, EG ו־GA.

    על פי נתונים אלו ונתוני הסרטוט, פי כמה גדול השטח השחור מהשטח הלבן?

    התשובה הסופית1תשובה (1)√2 + 1

    דרך הפתרון והסבר

    AE עובר דרך מרכז המתומן, ולכן הוא מחלק אותו לשני חצאים שווים: האפור הוא בדיוק חצי מהמתומן.שטח המתומן המשוכלל: 2(1 + √2)a², ועם a = 2:2(1 + √2) · 4 = 8 + 8√2, והאפור הוא 4 + 4√2.כל משולש לבן (EFG או GHA) בנוי משתי צלעות של המתומן, באורך 2, עם זווית של 135° ביניהן.הגובה מ־E אל המשך הצלע FG יוצר משולש 45-45-90 עם יתר 2, ולכן הגובה √2.שטח כל משולש לבן: 12 · 2 · √2 = √2, ולשניהם יחד 2√2.השחור הוא מה שנשאר מהחצי השני:4 + 4√2 − 2√2 = 4 + 2√2פי כמה גדול השחור מהלבן:4 + 2√22√2 = 42√2 + 1 = √2 + 1

    💡 הלקח במצולע משוכלל מחפשים אלכסון שחוצה אותו לחצי, ומחשבים רק את החלקים הקטנים – את השאר מקבלים בחיסור.
