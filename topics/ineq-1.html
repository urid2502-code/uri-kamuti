    נתחיל מהחלק המורכב במכנה: אחד חלקי מכפלה של שני שברים.1x − 3 · 1x + 3 = 1(x − 3)(x + 3)אחד חלקי זה הוא ההופכי: (x − 3)(x + 3) = x² − 9המכנה כולו:−7 + x² − 9 = x² − 16זה הפרש ריבועים: x² − 16 = (x − 4)(x + 4)הביטוי כולו:4 − x(x − 4)(x + 4)שימו לב: 4 − x = −(x − 4). נצמצם:−(x − 4)(x − 4)(x + 4) = −1x + 4 = 1−x − 4(x > 4, ולכן x − 4 ≠ 0 ומותר לצמצם.)התשובה: (3).

    💡 הלקח

    מפשטים מבפנים החוצה: 1/(שבר·שבר) = מכפלת המכנים; −7 + x² − 9 הוא הפרש ריבועים.

    🔁 דפוס חוזר: הפרש ריבועים a² − b² = (a − b)(a + b) – לא מחשבים ריבועים.

    מוקשים נפוצים

    4 − x ו־x − 4 שונים בסימן – הצמצום משאיר מינוס.

    נתון: x < |x| < 1 , y² < |y| < 1

    מה מהבאים נכון בהכרח?

    הצגת הפתרון

    התשובה הסופית4תשובה (4)אף אחת מהתשובות אינה נכונה בהכרח

    דרך הפתרון והסבר

    נפענח את הנתון על x:x < |x| קורה רק כש־x שלילי.|x| < 1, ולכן −1 < x < 0.נפענח את הנתון על y:y² < |y| קורה כש־0 < |y| < 1 (מספר שערכו המוחלט קטן מ־1 קטן מעצמו בריבוע).אבל הסימן של y לא ידוע: y יכול להיות 12 או −12.נבדוק את הטענות:(1) xy < 0 – נכון רק כש־y חיובי ✗(2) xy > 0 – נכון רק כש־y שלילי ✗(3) yx > 0 – אם y שלילי ו־x שבר (למשל x = −12), yx לא מוגדר ✗אף טענה לא בהכרח נכונה: התשובה (4).

    💡 הלקח

    x < |x| ⇔ x שלילי. y² < |y| ⇔ |y| < 1 – אבל הסימן של y לא ידוע.

    🔁 דפוס חוזר: ערך מוחלט |x| = מרחק מ־0. ל־x שלילי |x| = −x. שני ערכים מוחלטים שווים – שווים או נגדיים.

    🔁 דפוס חוזר: סימן של מכפלה ושבר בודקים את הסימן של כל גורם; x² ≥ 0 תמיד.

    מוקשים נפוצים

    הנתון y² < |y| קובע רק את הגודל של y, לא את הסימן שלו.

    איזו מהטענות הבאות נכונה בהכרח?

    הצגת הפתרון

    דרך הפתרון והסבר

    נשרשר את אי־השוויונות:b < |b + c| ו־|b + c| < a + b, ולכן b < a + b.מחסרים b: 0 < a. כלומר a חיובי.מהנתון a < b, ולכן גם b חיובי:0 < a < bלכן |a| < |b| ✓לגבי c אין מספיק מידע, ולכן (1) ו־(2) לא בהכרח; ו־(3) סותרת את מה שמצאנו (a חיובי).

    💡 הלקח

    משרשרים אי־שוויונות: b < |b + c| < a + b נותן מיד a > 0.

    🔁 דפוס חוזר: חיבור ושרשור אי־שוויונות מחברים אי־שוויונות באותו כיוון ומשרשרים – אסור לחסר.

    שאלה 3 מקבץ 14

    נתון: |a² + b²| = 2ab

    מה מהבאים נכון בהכרח?

    הצגת הפתרון

    התשובה הסופית3תשובה (3)a ו־b הם מספרים שווים

    דרך הפתרון והסבר

    a² + b² הוא סכום של ריבועים, ולכן אף פעם לא שלילי. הערך המוחלט לא משנה דבר:a² + b² = 2abנעביר אגף:a² − 2ab + b² = 0(a − b)² = 0a = bלכן a ו־b שווים: תשובה (3).למה לא נגדיים? אם b = −a אז 2ab = −2a², שלילי, ואילו a² + b² חיובי – לא ייתכן (חוץ מ־a = b = 0).

    💡 הלקח

    a² + b² = 2ab ⇔ (a − b)² = 0 ⇔ a = b.

    🔁 דפוס חוזר: זהויות של ריבוע (a ± b)² = a² ± 2ab + b²; (a + b)² − (a − b)² = 4ab.

    מוקשים נפוצים

    מספרים נגדיים נותנים 2ab שלילי, ולכן הם לא מתאימים.
